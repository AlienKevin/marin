# Simulator samples — what does each model think the terminal said?

The [world-model probe](/world-model-probe) reports one perplexity number per checkpoint. This page breaks that number open. For each held-out trajectory we give the model the first 14 (command, observation) pairs **plus the 15th command**, and ask for the **15th observation** — both *sampled* 5× (temperature 1.0, the SWE-bench decoding settings) and *scored* (teacher-forced env-PPL of the real observation). Agent framing throughout, so it lines up with the probe.

## The key axis: how much of the answer is already in context

A terminal observation can be one of two very different things. Sometimes it's a **re-display** of content the agent already saw — `sed -n '53,75p' index.js` after the file was `cat`'d three turns ago. Predicting that is an *in-context copy*. Other times it's **genuinely new** — a fresh `grep` hit, a test log, the first read of a file — which can only be *generated*. To separate these, every held-out target is scored for **copyable fraction**: what % of it appears verbatim (≥12-char spans) somewhere earlier in the model's context. We then stratify 49 trials across the spectrum.

**The per-bucket median env-PPL table below is the headline.** Read it left to right (easy → hard):

- **Retrieval trials (≥90% copyable): every arm is ~1.0.** When the answer is in context, even (a) 1M — the worst world model overall — reproduces it fine (1.07). These trials are *not* what separates the arms.
- **Pure-generation trials (<10% copyable): the arms split violently.** (a) 1M explodes to **≈20 PPL — worse than the untrained base** — because it has forgotten how to *be* a terminal and instead tries to act. (b)/(c) stay at ≈2.3. **This single bucket is where the entire global gap (1.07 vs 3.33) comes from.**
- The gradient between is monotone: as less of the observation is copyable, every model degrades, but (a) degrades *catastrophically* while (b)/(c) degrade *gracefully*.
- **Empty-output trials:** (b)/(c) (and a-1m) correctly predict a blank observation (~1.0); base hallucinates a wall of text (2.06).

So "(b) is a better world model than (a)" precisely means: **on the trials that require generating unseen content, (a) collapses and (b) doesn't.** They are indistinguishable on the easy (retrieval) trials. This is the quantitative form of *format generalizes, content memorizes* — and it's why no arm, not even (b), gets the pure-generation bucket near 1.0: emitting the literal contents of a never-seen file is the inherent ceiling.
